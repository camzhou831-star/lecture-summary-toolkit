## 本轮新增(原清单没有的)

- 来源编号体系 `S / P / F / H`,AI 只写编号,程序生成链接;点开能看原话、课件页图片、截图,有视频时定位播放
- 考点三分:🎯 老师明确说(必须引用转写)/ ⭐ 课堂重点 / 💡 AI 推测;仅课件模式禁止 🎯 ⭐ 与「老师说」
- 回复检查:不存在的编号、模式不符的引用、截断(结束标记)、缺小节、粘错任务、自写时间戳(越界判错,其余提醒)
- 阶段级恢复:指纹缓存、失败只重跑失败阶段、取消与关窗口会停掉子进程、重启后标「中断」可继续
- 诊断信息导出(不含课程正文、文件名与路径)

## 已知限制 / 未验证

- Windows 完全未实测;视频模式在 Windows 上会直接提示改用字幕/课件模式
- 转写与抓帧是**顺序**执行(CLI 的 `prepare.sh` 是并行),2 小时课多花约 15 秒
- 恢复粒度是阶段:转写中途中断会从头重转这一节(2 小时课在本机约 2 分钟)
- 去重对「同一页上的手写批注」可能保留不全:OCR 合并规则按文字判断,批注本身没有文字。未专门评估
- 普通 Windows 笔记本、无独显电脑的处理速度没有实测数据
- 真实 ChatGPT / Claude 网页版的回复格式遵守程度未实测(检查逻辑用的是构造的回复)
