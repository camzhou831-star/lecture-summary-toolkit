# 新手真人测试清单(发布门禁第 1 项)

> 目的:验证不会命令行的同学,能不能只看 README 独立用起来。对应方向文档第七节门禁:**3 位非技术 Mac 用户,至少 2 人在 20 分钟内完成字幕总结**。
> 测试时你只看、只记录,**不给任何口头指导**。对方卡住超过 3 分钟、明确求助时才介入,并把介入记为一次"人工干预"。

## 测试前准备(你来做)

- [ ] 在 GitHub 上发布一个测试版 Release(如 `v0.1.0-rc1`),确认两个 zip 都能下载。
- [ ] 准备一份**合成或公开**的字幕文件给对方用,不要用真实课程录播的字幕(版权)。可以用 `examples/demo/课程视频/` 里示例视频的 `.srt`,或者找一段公开讲座的字幕。
- [ ] 对方电脑上已经装好并登录了某个 AI 应用(记下是哪个、什么版本)。没有的话,只测网页版。
- [ ] 准备计时器和本表。

## 给对方的任务(只说这一段)

> "这是一个把课程字幕变成复习笔记的工具。请打开这个 GitHub 页面,按页面上的说明,把这份字幕做成一份总结。遇到问题先自己想办法,想说什么就说出来。"

## 重点观察

1. **选 zip**:看了 README 第一屏,能不能选对?会不会去下 "Source code"?
2. **解压**:是双击解压吗?中文文件夹名有没有出问题?
3. **打开文件夹**:会不会用 AI 应用打开文件夹(这一步各家客户端不一样,最容易卡住)。
4. **第一句话**:是照抄 README 的示例,还是自己说?AI 有没有正确触发流程?
5. **单元和日期**:AI 问的时候,对方能不能答上来?
6. **语言**:英文母语的同学,AI 全程用英文回复了吗?
7. **权限弹窗**:AI 应用要求授权读写文件或运行命令时,对方敢不敢点允许?看不看得懂?

## 通过标准

- 3 人中至少 2 人在 20 分钟内拿到通过检查的总结(网页版的标准是拿到结构完整的总结)。
- 记录每一处卡住的地方。同一处有 2 人以上卡住,改 README 或流程后再测。
