# 课程笔记工作台 · 一页使用说明

把一节课(录播视频、字幕或课件)整理成**每条重点都能点开核对原文**的学习笔记。不需要会命令行,用你平时的 ChatGPT / Claude 网页版就行。

## 你需要

- 一台 **Mac**(处理录播视频目前只支持 Mac;Windows 可以用「字幕」和「仅课件」两种方式,尚未实测)
- 自己下载好的录播 / 字幕 / 课件 PDF
- 一个 ChatGPT 或 Claude 网页版账号

电脑上需要有 Python 3(macOS 一般自带;没有的话双击启动时会提示)。第一次处理视频前,还需要装几个免费工具(只需一次):打开「终端」,粘贴下面这行后回车:

```
brew install ffmpeg whisper-cpp tesseract poppler
```

没有 `brew` 的话先照 https://brew.sh 首页那一行命令装上。只用字幕可以跳过这一步;用课件 PDF 至少需要其中的 `poppler`。新建任务时,页面会告诉你这台电脑还缺什么。

> 目前可以放心试用的范围:**Mac + 字幕模式 / 仅课件模式**;Mac 上的视频模式已在作者电脑上验证,别的 Mac 还需要有人协助第一次安装。Windows 没有实测过。

## 五步用法

1. **双击「启动工作台」**。会弹出一个黑色窗口(别关它),浏览器自动打开工作台页面。
2. **新建任务**,选你手上的材料:
   - 录播视频:在本机把语音转成文字、抓取画面。第一次会下载约 1.6 GB 的语音模型。
   - 字幕文件(.srt / .vtt):录播平台能下载字幕时选这个,最快,不需要语音模型。
   - 只有课件 PDF:笔记只根据课件,不会有老师口述的内容。
   
   再点「+ 课件 PDF」把本周课件加上(可选,但能让笔记带上课件页码)。选视频**不会移动或复制**你的文件。
3. **点「开始处理」**。页面会显示每一步的进度。这时可以关掉浏览器,处理会继续;但别关黑色窗口。
4. **交给 AI**:在「③」里
   - 下载「AI 材料」文件(材料里的文字会发给你选的 AI 服务);
   - 打开 ChatGPT / Claude 网页版,新建对话,把文件拖进去;
   - 回工作台点「复制提示词」,粘贴到同一条消息里发送。
5. **贴回来**:把 AI 的完整回复复制下来,粘贴到「④」,点「检查并保存」。在「⑤」里看笔记:
   - 蓝色小标签就是来源,点一下右边会显示那段原话、那页课件或那张截图;有视频时可以直接跳到那一刻播放;
   - 「检查结果」会列出 AI 编造的来源编号、被截断的回复、缺少的小节等;
   - 可以导出 Markdown、Obsidian 格式、网页,或打印成 PDF。

## 常见问题

| 情况 | 怎么办 |
|---|---|
| 页面显示「请从启动程序打开」 | 关掉页面,重新双击「启动工作台」 |
| 某一步失败了 | 看红框里的「下一步」;点「重试」只会重做失败的那一步,前面完成的不会重做 |
| 不小心关了黑色窗口 | 重新双击「启动工作台」,任务显示「中断」,点「继续」 |
| AI 回复停在一半 | 在 AI 那里说「继续」,把后半段接在前半段后面一起贴回来 |
| 检查说「没有结束标记」 | AI 回复最后应有一行【LSK 结束】。如果你确认回复是完整的,可以忽略这条提醒 |
| AI 说文件太长 / 读不全 | 在「③」里改用「分段复制」,一段一段发,最后用「整合提示词」合成一份 |
| 检查说「引用的来源不存在」 | AI 编了编号。让它改,或者自己删掉这条引用 |
| 课件提示「没有可提取的文字」 | 这份 PDF 是扫描版。换一份能选中文字的 PDF |
| 双击「启动工作台」提示无法打开 | 在「启动工作台」上点右键 → 打开 → 再点「打开」(macOS 对下载文件的保护) |

## 数据去哪了

- 转文字、抓画面、识别画面文字、读课件:**都在你的电脑上**。
- 你把 AI 材料发给 ChatGPT / Claude 时,材料里的**文字**会发到对应公司的服务器。
- 工作台只在本机运行,同一 Wi-Fi 下的其他设备访问不到。
- 录播和课件的版权属于学校和老师,请只用于个人学习,不要把笔记和材料公开分享。

「检查通过」只说明格式和来源编号没问题,**不代表内容一定正确**。考试前请点来源核对重点内容。
