**Which file do I download? / 下载哪个文件?**

- `lecture-summary-web-prompts-*.zip` — **no install.** You only have subtitles (.srt/.vtt) and use a web AI (ChatGPT, Claude, Gemini, Grok). Unzip, read `README.txt`.
  **不用安装。** 只有字幕、用网页版 AI 时下载这个,解压后看 `README.txt`。
- `lecture-summary-toolkit-*.zip` — **full version.** For an AI app that can work with files on your Mac (Codex, Claude Code / Claude desktop, Gemini CLI). Adds automatic checks, links back to the recording and a cross-week exam bank. See README.
  **完整版。** 用能操作本机文件的 AI 应用(Codex、Claude Code / Claude 桌面版、Gemini CLI)时下载,多了自动检查、回跳录播、跨周考点库。见 README。

Ignore "Source code (zip / tar.gz)" — those are for developers. / 页面下方的 "Source code" 是给开发者的,不用下。
