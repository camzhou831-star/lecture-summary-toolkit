# 总结工作台构想（11-23 草稿，11-24 开工前过一遍）

## 一句话

把「录播课总结工具」从「先自己下好录播课，再让 AI 读文件夹」改成一个本地工作台：**贴链接或拖文件进来 → 自动拿到带时间戳的文字稿 → 选一个模板（课程总结 / 对标拆稿 / 会议纪要）→ 出总结并自动核对时间戳**，历史都留在工作台里能翻能搜。

## 你问的那个问题：新拉片流程能不能拿网页上的东西？

能，但有边界。新流程里的 `tools/script_fetch.py`（11-20，Windows 原件，已同步到 Mac）把四种来源统一成「带时间戳的 srt + 纯文本 + 作品数据」：

| 来源 | 怎么拿 | 11-20 实测 |
|---|---|---|
| 抖音 | `dy_fetch/dl_anon.cjs` 匿名开作品页下片 → ffmpeg 抽音频 → whisper | 9 条拿到 6 条；连续请求会被拦，每条间隔 20 秒 |
| B 站 | yt-dlp 匿名只拿音频 → whisper | 可以；官方 AI 字幕要登录，不用 |
| YouTube | yt-dlp 直接下自动字幕，不用转写 | 可以；别用通配要翻译字幕（429） |
| 本地文件 | 已有视频 / 音频 → whisper | 可以 |

它的输出（srt）正好就是录播课工具的输入，所以两边能直接接上。

**拿不到的**：
- **学校录播课（Echo360 / LMS）**：要登录，匿名脚本拿不到。只能你自己在浏览器里下载或导出字幕，然后拖进工作台（和现在一样）。以后可以考虑浏览器插件「一键把当前页的字幕/视频交给工作台」，用的是你自己的登录态。
- **纯文字网页（文章、公众号、文档）**：现在两套流程都没有。要加一个「网页正文抓取」来源，没有时间戳，只能走「普通总结」，没有时间线核对。

## 结构

```
┌ 输入层（新） ──────────────────────────────┐
│ 链接：抖音 / B站 / YouTube（复用 script_fetch）│
│ 文件：mp4 / mp3 / srt / vtt / txt / pdf 课件   │
│ 网页正文（新，第二期）                          │
└──────────────┬─────────────────────────────┘
               ▼ 统一成：transcript.srt + meta.json + 来源.txt
┌ 处理层（复用录播课工具 工具/*.py） ─────────────┐
│ prepare：分段、抽帧、OCR 课件、去重              │
│ 模板：课程总结 / 对标拆稿（拉片 skill 的拆稿口径）/ 会议纪要 │
│ 写总结：调大模型 API（新）                        │
│ finish：check_summary 核对时间戳、课件页、回跳链接 │
└──────────────┬─────────────────────────────┘
               ▼
┌ 工作台界面（新） ───────────────────────────┐
│ 任务队列（下载 / 转写 / 总结 进度）              │
│ 资料库：每条一张卡片，点开看总结 + 原视频跳转       │
│ 搜索、标签、导出 Markdown / Obsidian            │
└────────────────────────────────────────────┘
```

**和现在最大的区别**：现在「写总结」这一步是交给你自己的 Claude Code / Codex 去做（工具只准备材料和核对）。工作台要自己调模型 API 才能一键出结果。建议两种都留：
- **API 模式**：填 DeepSeek / 任意 OpenAI 兼容 Key（和简账 AI 助手同一套配置方式），一键出总结。
- **AI 应用模式**：照旧，工作台只准备材料，生成一段提示词，交给 Claude Code 写，再回来核对。

## 技术选型（建议）

- **本地网页应用**：Python FastAPI 后端 + 一个简单前端（React + Vite，或先用纯 HTML），`localhost` 打开。理由：录播课工具和 script_fetch 都是 Python，直接 import；Mac / Windows 都能跑；以后要做成桌面版再套 Electron 或 Tauri。
- 下载转写复用现成的：yt-dlp、whisper-cli、ffmpeg、playwright（Mac 上 11-23 都装好了）。
- 存储：SQLite 记任务和资料卡片，文件还放在 `总结/`、`课程视频/`、`画面/` 现有目录里。
- 注意 `script_fetch.py` 里 whisper 路径写死成 Windows 的 `whisper-cli.exe`，接进工作台要改成按系统找（Mac 是 `/opt/homebrew/bin/whisper-cli`）。

## 明天（第一天）做到哪

目标：**贴一个 B 站或 YouTube 链接，能在网页上看到带时间线的课程总结**。

## 风险

- 平台限制会变：抖音匿名接口随时可能失效，B 站 / YouTube 也会限流。每种来源要有「失败了就提示用户自己下载再拖进来」的退路。
- 版权和平台规则：下载他人视频只做个人学习研究，工作台不提供再分发；对外发布时要在说明里写清楚。
- whisper 在片尾会编句子、专有名词错得多（拉片笔记里记过），总结前要保留「人工核结尾」这一步的提示。
