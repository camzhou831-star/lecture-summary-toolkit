## 一句话概括

循环难测是因为循环体可能跑 0 次、1 次或多次,每种次数都可能藏着不同的 fault,行覆盖看不出来;实践用"0 / 1 / 多次"三个测试的非正式启发式,理论上用素路径覆盖把它形式化。

## 核心要点

1. **循环为什么难测**(00:22–00:42,p2):循环体可以执行 0 次、恰好 1 次或多次,每种情况可能暴露不同的 fault;行覆盖只说明"这行跑过",不说明跑了几次。
2. **循环覆盖启发式**(00:42–01:00,p3):写三个测试——循环体不执行、恰好执行一次、执行多次。非正式,但能抓住大量 off-by-one 错误。
3. **素路径(prime path)**(01:00–01:18,p4):**简单路径** = 不重复访问任何节点的路径;**素路径** = 不能再延长而不重复节点的简单路径。素路径覆盖蕴含节点覆盖与边覆盖。
4. **例子**(01:18–01:33,p5):`while i < n: total += a[i]; i += 1`——n=0 循环体不跑,n=1 跑一次,n=3 跑三次,三个测试即得到循环覆盖。
5. **总结与考试提示**(01:33–01:46,p6):记住"0、1、多次";需要严格时用素路径;🎯 下周 quiz 覆盖这套课件。
