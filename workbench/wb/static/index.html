    写总结用哪个 AI

    有 Claude Pro / Max 或 ChatGPT Plus / Pro 的话,装好对应的命令行工具并登录一次就能用,不用 API Key,用量算在你的订阅里。没有订阅才需要 API Key:写进 的 api_key。

    网站登录

    学校的 Panopto / Echo360 / Kaltura、Coursera、Udemy 这类要登录的视频:选一个你已经登录过的浏览器,下载时借用它的登录状态。只在本机用,不上传;不需要就保持"不用"。

    配色

    低饱和的绿、紫、蓝绿看着更放松。深浅色跟随系统,也可以点顶栏的月亮手动切。
