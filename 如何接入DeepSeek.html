用 DeepSeek 写总结:5 分钟接好

总结工作台负责下载视频、转文字、核对时间戳;"写总结"这一步要借一个 AI。国内最省事的是 DeepSeek。这份说明从零开始,一步一步带你接好。

先弄清楚一件事

DeepSeek(深度求索)是国内的 AI,和 ChatGPT 差不多,在国内直接能用。手机上的 DeepSeek App 是免费聊天用的,工作台用的是它的「开放平台」:要单独充一点钱,拿一把叫 API Key 的"钥匙",按用量扣费。

准备好这三样

  • 一个手机号(登录用)
  • 支付宝或微信(充值用)
  • 工作台已经打开(双击「启动工作台」后,浏览器里的那个页面)

五步接好

  1. 打开 DeepSeek 开放平台,登录 在浏览器里打开 platform.deepseek.com,用手机号登录。没有账号的话,第一次登录就会自动注册。
  2. 充一小笔钱 在左边菜单找「充值」,用支付宝或微信充一点,第一次可以先充 10 元左右试试。价格以官网的价格页面为准。
  3. 创建 API Key,复制下来 在左边菜单找「API keys」,点「创建 API key」,名字随便写(比如"总结工作台"),确认。页面会出现一串 sk- 开头的字符,这就是 Key。
    这串字符只显示这一次,关掉就看不到了。马上点旁边的复制按钮。万一没复制到,删掉它再创建一个就行。
  4. 粘贴到工作台 回到工作台首页,在顶部「开始前检查」里找到 DeepSeek 那一项,把 Key 粘进输入框,点「保存」。工作台会先试一下这把 Key 能不能用,对了才保存。
    也可以在左边「设置 → 写总结的 AI」里粘贴。
  5. 看到「准备就绪」就好了 首页顶部出现「准备就绪:DeepSeek … 写课程总结」,就可以贴链接或选文件开始了。

常见问题

提示「Key 不对」
多半是复制时少了几个字符。回到开放平台,删掉这把 Key,重新创建一把再粘贴。
提示「余额不足」
开放平台里的钱用完了。去「充值」充一点,回到工作台点「重跑」。
大概花多少钱?
按处理的字数扣费,课越长越贵。为了不把错的内容写进总结,课程总结写完还会审核、复核几轮,这部分会比写总结本身多花一些。开放平台的「用量信息」里能看到每天花了多少。
Key 安全吗?
Key 只存在你自己电脑上(工作台的配置文件里),工作台不会把它发到别处。不要把 Key 发给别人;万一泄露了,到开放平台把它删掉,再建一把新的。
不想单独付钱
如果你有 ChatGPT Plus 或 Claude Pro 会员,可以改用 Codex 或 Claude Code 写总结,不需要 API Key(安装方法见首页「开始前检查」)。
页面和这份说明对不上
开放平台可能改过版。按意思找「充值」和「API keys」这两个地方就行。

这份说明随工作台一起下载,在工作台首页 DeepSeek 那一项旁边也能打开。
